# Página de vendas — Acervo Pedagógico

Página única (`index.html`), sem dependências externas: CSS e JS inline, ilustrações em SVG, fontes do sistema.

## Antes de publicar
- Troque `LINK_CHECKOUT_BASICO` e `LINK_CHECKOUT_PREMIUM` pelos links de checkout.
  Os parâmetros da URL da página (ex.: `?sck=...`, `utm_*`) são repassados automaticamente para esses links.
- Confira preços, bônus e prazos de garantia na seção `#planos`.
- Substitua os depoimentos de exemplo por depoimentos reais (com autorização).
